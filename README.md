# Java Learning Journey — Personne

**Building a strong foundation in Java and Object-Oriented Programming, one project at a time.**

A practical Java project focused on understanding the fundamentals of Object-Oriented Programming (OOP) through the design and implementation of a `Personne` class.

This repository is part of my ongoing journey in software development: learning core concepts, applying them through hands-on exercises, and building a solid foundation for more advanced projects.

---

## Overview

The project models a person using attributes, constructors, and methods. It provides a simple environment to practice object creation, constructor overloading, encapsulation, and basic object behavior.

Rather than focusing only on writing code that works, the goal is to understand **why the code works, how its components interact, and how Java structures object-oriented applications.**

## Concepts & Skills

- **Classes and Objects** — defining a class and creating instances.
- **Encapsulation** — declaring attributes with `private` access.
- **Constructors** — initializing objects with different sets of parameters.
- **Constructor Overloading** — providing multiple ways to create a `Personne`.
- **Instance Methods** — implementing behavior through methods.
- **Object State** — updating and displaying a person's information.
- **Java Fundamentals** — working with strings, integers, conditions, and console output.

## Features

- Create a person using three constructor variations.
- Store personal information: last name, first name, gender, and age.
- Increment a person's age using `anniversaire()`.
- Display a person's information using `presenteToi()`.
- Practice organizing Java code into separate classes.

## Getting Started

### Prerequisites

- A compatible Java Development Kit (JDK)
- Apache NetBeans or another Java IDE
- Apache Maven, or an IDE that supports Maven projects
- Git (optional, for cloning the repository)

### Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/localbtstudio-tech/java-learning-journey-personne.git
```

**2. Open the project**

Open the cloned `personne` folder in Apache NetBeans as a Maven project.

**3. Run the application**

Open `TestPersonne.java` and run the file to execute the examples and observe the program's output.
